# 待办清单网页版
一个简单的本地待办任务管理页面，支持任务新增、删除、状态统计，数据保存在浏览器本地存储，刷新页面不会丢失。

## 功能说明
- 添加任务：输入内容，点击添加按钮新增待办
- 删除任务：点击任务右侧删除按钮移除任务
- 数据持久化：使用 localStorage 存储，关闭页面再次打开数据保留
- 统计面板：展示总任务数、已完成、未完成数量
- 自适应布局，页面随内容自动撑开

## 技术栈
HTML + CSS + JavaScript，无框架，纯前端，不需要后端服务，直接浏览器打开即可运行

## 使用方式
1. 下载 index.html 文件
2. 双击文件，直接用浏览器打开
3. 开始添加、管理你的待办事项
